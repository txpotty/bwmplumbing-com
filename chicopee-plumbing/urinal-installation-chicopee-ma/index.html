    Residential Urinal Plumbing in Chicopee, MA

    Home urinals use the same rules as commercial ones. The drain is usually 2 inch, the trap is built into the china, the fixture needs a vent within code distance, and the flush valve needs either a 3/4 inch supply or a lower-flow residential valve on 1/2 inch. Your city may want a permit. We check that first.

    Waterless Cartridge Urinals in Chicopee

    Each waterless brand uses its own cartridge. Falcon, Waterless Co, Kohler and Zurn units all trap odor differently, and the cartridge or sealing liquid has to be replaced after a set number of uses, which in a busy restroom can mean every few months. We set up a schedule with you. Spare cartridges should stay on site.

    Flushometer Urinal Installation in Chicopee

    Manual flushometers are still the most common setup. Manual valves go on a 3/4 inch line with the control stop tuned and the vacuum breaker at the correct height. Handles can go left or right. ADA units need the handle within reach.

    Sensor Urinal Installation in Chicopee, MA

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Expect years between battery changes. Hardwired units need an electrician first.

    ADA-Compliant Urinal Installation in Chicopee

    At least one urinal in a public restroom with more than one usually has to be accessible. That means a rim no higher than 17 inches above the floor, an elongated bowl projecting at least 13-1/2 inches from the wall, and a 30 by 48 inch clear floor space in front. The flush handle has to be easy to reach. We mark it all during rough-in.

    Flush Valve Urinal Installation in Chicopee, MA

    Flush valve urinals are the commercial standard. Tankless flushometers deliver a set volume from a 3/4 inch line and recover instantly for the next user. We set the volume to the bowl. Wrong settings stain bowls.
